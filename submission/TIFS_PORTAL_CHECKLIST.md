# IEEE TIFS Author Portal Checklist

## Recommended classifications

- Primary EDICS: `ADP` / `IFS-ADP` -- Anonymization and Data Privacy.
- Secondary EDICS, if the live portal permits it: `NET` / `IFS-NET` --
  Network Security.
- Optional cross-domain keyword, not a substitute for TIFS EDICS:
  distributed/federated learning over graphs.

The corresponding author must use the codes and labels displayed by the live
portal. Historical Unified EDICS documents use the `IFS-` prefix, whereas the
current TIFS page may display the shorter first-level code.

## Metadata

- [ ] Exact title matches the manuscript.
- [ ] Author names, order, affiliations, emails, and ORCIDs match
  `AUTHOR_METADATA.template.md`.
- [ ] Corresponding author is designated.
- [ ] Abstract matches the final PDF and remains within the current word
  limit.
- [ ] Keywords are entered consistently.
- [ ] Funding agencies and grant identifiers are entered exactly.
- [ ] Conflicts of interest are declared, or an explicit none declaration is
  supplied.
- [ ] Prior submission/rejection history and related manuscripts are
  disclosed.
- [ ] Suggested/opposed reviewers are justified without conflicts.

## Files and declarations

- [ ] Main PDF is the final compiled artifact.
- [ ] Source archive contains all LaTeX, bibliography, and figure sources.
- [ ] Public artifact URL resolves and the tagged commit is immutable.
- [ ] External theorem-review memorandum is complete.
- [ ] Dataset-rights attestation is complete.
- [ ] AI-use disclosure is approved by all authors.
- [ ] Page count and any overlength implications are confirmed against the
  live TIFS instructions.
